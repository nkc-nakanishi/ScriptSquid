# ScriptSquid
A lightweight C# file analyzer that scans .cs files and displays line count, size, updated time, and full path. Includes filter expressions, history, and command list viewer.

本リポジトリは「公開可想定実験プロジェクト」です。
商用プロダクトではありませんが、公開しても問題ない品質を満たしています。
目的は以下の技術実験です：
- コードUI設計の検証
- 軽量ファイル解析ツールの構築
- フィルタ式パーサーの実装実験
- CommandList 外部読み込みの検証
