# ScriptSquid
A lightweight C# file analyzer that scans .cs files and displays line count, size, updated time, and full path. Includes filter expressions, history, and a command list viewer.

This repository is a public-ready experimental project. It is not intended as a commercial product, but it is stable and suitable for public sharing. The goal of this project is to explore:

- code-based UI design
- lightweight file analysis tooling
- filter expression parsing
- external command list integration
