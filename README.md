# ScriptSquid
A lightweight C# file analyzer that scans .cs files and displays line count, size, updated time, and full path. Includes filter expressions, history, and command list viewer.

This repository is an "experimental public-ready project".
It is not a commercial product, but it is stable enough to be shared publicly.
The purpose of this project is to explore:
- code-based UI design
- lightweight file analysis tools
- filter expression parsing
- external command list loading
